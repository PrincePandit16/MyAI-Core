# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-10-28
### Added
- Initial MVP release.
- FastAPI backend with JWT authentication.
- React frontend with Vite and Tailwind CSS.
- RAG pipeline integration with Milvus vector store.
- Support for multiple LLM providers (Local Llama, TGI, Groq).
- Infrastructure orchestration via Docker Compose.
- Prometheus and Grafana monitoring setup.
- Project documentation (Architecture, Dev Guide, Ops Guide).
